# 工作台前端设计约定（2026-11 重做）

本文记录 `src/client` 的视觉令牌、布局、动效和交互约定。新增面板或调整界面时请遵循这些约定，避免重新出现补丁式样式。

## 1. 设计令牌

所有颜色、字号、圆角和动效时长都定义在 `styles.css` 开头的 `.vs-studio` 上，并按 `data-scheme="light|dark"` 切换。

| 类别 | 令牌 | 说明 |
| --- | --- | --- |
| 表面 | `--vs-bg` `--vs-surface` `--vs-surface-2` `--vs-surface-3` `--vs-field` `--vs-stage` | 背景 → 面板 → 抬升/悬停；舞台使用更深（深色）或更暗（浅色）的 `--vs-stage` |
| 线条 | `--vs-line` `--vs-line-strong` | 分隔线、控件边框 |
| 文字 | `--vs-text` `--vs-text-2` `--vs-text-3` | 主文字、说明、弱化 |
| 强调 | `--vs-accent` `--vs-accent-strong` `--vs-on-accent` `--vs-accent-soft` | 唯一品牌色，仅用于主操作、选中和进度 |
| 状态 | `--vs-danger(-bg)` `--vs-warning(-bg)` `--vs-info(-bg)` | 错误、待处理、提示 |
| 素材类型 | `--vs-kind-image/text/audio/video` | 资产缩略图与关联图标 |
| 画布 | `--vs-g-*` | LiteGraph 画布通过 `getComputedStyle` 读取，主题切换时自动重绘 |
| 字号 | `--vs-fs-xs` 11 · `sm` 12 · `md` 13 · `lg` 15 · `xl` 18 · `2xl` 26 | 最小 11px |
| 圆角 | `--vs-radius-sm` 7 · `md` 10 · `lg` 14 · `999px`（胶囊） | |
| 动效 | `--vs-dur-1/2/3`（120/200/320ms），`--vs-ease-out`，`--vs-ease-spring` | |

旧变量名（`--vs-panel`、`--vs-border`、`--vs-muted` 等）保留为别名，供既有面板规则使用；新代码请直接使用上表中的令牌。

## 2. 布局

`Studio.tsx` 通过 `ResizeObserver` 测量工作台自身宽度，在根元素写入 `data-layout`：

| `data-layout` | 宽度 | 结构 |
| --- | --- | --- |
| `wide` | ≥ 1180px | 资产库 · 舞台（监视器 / 分镜画布 / 分栏）+ 时间线 + 底部抽屉 · 属性 |
| `medium` | 780–1180px | 资产库变为左侧滑出层；顶栏收起阶段文字与按钮文字 |
| `narrow` | < 780px（DSH 右侧栏） | 单列：舞台 → 时间线 → 分段切换「属性 / 资产 / 工作面板」 |

按工作台宽度而不是视口宽度判断，是为了让右侧栏在宽窗口里也能得到紧凑布局。工具栏和画布内部另有 `@container` 规则，它们没有 `position:fixed` 后代，可以安全地建立容器。

| 文件 | 职责 |
| --- | --- |

| `Stage.tsx` | 舞台容器：监视器 / 分镜画布 / 分栏三种视图切换、输出规格入口、用文字修改弹层（⌘K） |

| `Timeline.tsx` | 按时长比例的镜头片段、播放头、拖拽排序（插入标记）、键盘移动和删除 |
| `PropertiesPanel.tsx` | 镜头 / 资产 / 影片属性；折叠状态写入 `localStorage`；修改型操作期间显示锁定提示 |
| `BottomDrawer.tsx` | 可折叠、可拖拽调高的面板抽屉；其他入口通过 `openPanel()` 打开并聚焦 |

| `icons.tsx` | 统一 24 栅格图标、`Button`、`IconButton` |

## 4. 交互约定

- **反馈分层**：成功和可恢复的错误用 Toast；需要用户决定的情况（保存冲突、本地未保存、任务失败）用工作区顶部横幅；破坏性操作先确认。
- **删除**：删除镜头立即生效并提供 6 秒「撤销」；删除资产先确认再提供撤销；画布上的资产节点按 Delete 只解除关联。用户继续编辑后，未使用的撤销提示自动失效。
- **生成**：已有分镜时重新生成需要确认。生成期间只锁定写操作，播放、浏览面板和历史仍可用。
- **预览与编辑**：修改型任务和手动「检查资源并刷新预览」运行时，界面锁定写操作，并在 0.3 秒后显示原因。保存后若预览落后，`controller.refreshPreview()` 约 1.2 秒后请求宿主准备该版本的预览资源。宿主在工程队列中处理准备和保存，自动刷新期间可以继续输入。
- **多入口播放**：每个打开的工作台有自己的播放位置，监视器、时间线与分镜画布在当前工作台内同步。
- **面板入口**：任何打开面板的按钮都调用 `openPanel(tab)`，展开抽屉、滚动到可见位置、聚焦选中的 Tab 并闪烁提示。
- **空格**：在输入框以外的任何位置都可以播放或暂停；鼠标点击过的按钮不会吞掉空格，键盘 Tab 聚焦的按钮保留原生激活。画布上的空格同样转发给监视器。
- **步进器**：状态来自工程数据（镜头与主链、预览是否已构建并与当前版本一致、成片是否对应当前版本），点击跳到对应视图。

## 5. 动效

- 悬停 120ms，按下 `scale(.97)`；聚焦显示 2px 强调色描边环。
- 弹层、弹窗、Toast 用缩放加淡入；抽屉展开从高度 0 生长；折叠组用 `grid-template-rows` 过渡。
- 画布 `focus()` / `fit()` 以 260ms 缓动平移和缩放；时间线播放头在非播放状态下平滑移动。
- 步进器完成时勾选动画，进行中显示旋转与流动进度条。
- 系统开启「减少动态效果」时，所有动画和过渡被压缩为瞬时（加载旋转保留低速）。

## 6. 验证

- `node --import tsx --test tests/studio-interaction.test.ts`：确认框、撤销、抽屉聚焦、空格播放、数字草稿、锁定提示、步进器、资产搜索、画布 Delete。
- `node scripts/visual-harness.mjs <label>`：在 1440 / 1024 / 720 宽度和浅色 / 深色下挂载真实 `Studio` 与内存 API，截图输出到 `.local/visual-redesign/<label>/`。该脚本不随包发布。
