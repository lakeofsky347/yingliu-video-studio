# yingliu-video-studio 0.8.1

- 在 DSH 会话顶部选择 **映流** 标签页，即可打开视频工作台。
- 点击会话右上角的 **在右侧打开映流**，或在 DSH 右侧栏的「开始」页选择 **映流 · 视频工作台**。影片在右侧查看和编辑，左侧可继续使用当前对话。
- DSH 左侧导航的胶片图标可进入全宽工作台，适合需要更多空间的分镜和源码编辑。

顶部标签页和右侧入口由 DSH 提供的会话与右侧栏接口支持。缺少对应接口的旧版宿主可以通过左侧导航打开工作台。

在 **插件管理 → 添加插件** 填写 `yingliu-video-studio-0.8.1.tgz` 的绝对路径，安装后启用。从 npm 安装对应的已发布版本时，使用 `yingliu-video-studio@0.8.1`。

0.8.1 继续使用 schema v3。若从更早的版本升级，工程备份、旧工程制作方式确认和 `expectedRevision` 要求见 [0.8.0 发布说明](RELEASE-0.8.0.md)。源码基线见 [SOURCE.json](../SOURCE.json)。
