# yingliu-video-studio 0.8.2

打开 **模型与素材生成 → 配置模型连接**，填写接口协议、服务地址和 API Key，再点击 **保存连接**。对于支持模型目录的提供商，模型中心会自动查询并显示可选模型。选择模型后，按需要确认显示名称和参数，再点击 **保存模型**。

已保存的连接可以点击 **拉取模型列表** 刷新目录。支持 OpenAI 兼容的 `/models`、Gemini、火山方舟，以及提供原生模型目录的阿里云百炼地址。

目录查询只读取模型列表。提供商没有公开目录、凭据权限不足或查询失败时，仍可在「连接中的模型」手动填写服务端模型 ID。实际生成能力取决于模型、账号和接口协议。

在 DSH 的 **插件管理 → 添加插件** 填写 `yingliu-video-studio-0.8.2.tgz` 的绝对路径，安装后启用。从 npm 安装对应的已发布版本时，使用 `yingliu-video-studio@0.8.2`。

会话顶部标签和右栏并排用法见 [0.8.1 发布说明](RELEASE-0.8.1.md)。工程备份、旧工程制作方式确认和 `expectedRevision` 要求见 [0.8.0 发布说明](RELEASE-0.8.0.md)。
